# E-Commerce Website Development Project

## 1. Project Overview

The E-Commerce Website is a web-based platform designed to allow customers to browse products, add products to their shopping cart, place orders, and make payments online. The platform will also provide vendors with the ability to manage their products, inventory, and orders, while administrators will manage users, vendors, products, transactions, and overall platform activities.

## 2. Project Objectives

- Develop a user-friendly e-commerce platform.
- Enable customers to purchase products online.
- Allow vendors to manage products and inventory.
- Provide administrators with centralized platform management.
- Implement secure authentication and authorization.
- Develop REST APIs for frontend and backend communication.

## 3. User Roles

### Customer
- Register and log in.
- Browse and search products.
- View product details.
- Add products to cart.
- Place orders.
- Track orders.
- Manage profile and addresses.

### Vendor
- Register and log in.
- Manage vendor profiles.
- Add, update, and delete products.
- Manage inventory.
- View and process customer orders.

### Administrator
- Manage customers and vendors.
- Approve or reject vendor registrations.
- Manage product categories.
- Monitor orders and payments.
- View platform reports and analytics.
